# How to Request Changes Using Issue Templates

This guide explains how teachers can use GitHub issue templates to request changes to the Mergington High School Activities website.

## Why Use Issue Templates?

Issue templates help you:
- **Provide all necessary information** without worrying about what to include
- **Get faster results** because developers have everything they need
- **Track progress** on your requests in one place

## Getting Started

When you want to request a change:

1. Go to the [Issues tab](../../issues) in GitHub
2. Click the green **"New issue"** button
3. Choose the template that matches your request
4. Fill out the form with your information
5. Click **"Submit new issue"**

That's it! The system will take care of the rest.

## Which Template Should I Use?

### 🐛 Bug Report
**Use when:** Something isn't working correctly or looks wrong

**Examples:**
- "The website colors don't match our school colors"
- "Student registration isn't working"
- "Activities aren't showing up in the list"

### ✨ Feature Request
**Use when:** You want to add something new to the website

**Examples:**
- "Add difficulty levels (Beginner, Intermediate, Advanced) to activities"
- "Add a calendar view for activities"
- "Allow students to favorite activities"

### 📚 Activity Change Request
**Use when:** You need to add, update, or remove an activity

**Examples:**
- "Add a new Robotics Club"
- "Change Chess Club schedule to Wednesdays"
- "Remove Drama Club (canceled for this semester)"
- "Increase Basketball Team participant limit to 20"

### 🎨 UI/Design Improvement
**Use when:** You want to improve how the website looks or feels

**Examples:**
- "Make text larger for better readability"
- "Improve color contrast for accessibility"
- "Add school mascot images to the header"
- "Make the website work better on mobile phones"

### 💬 General Request
**Use when:** Your request doesn't fit the other categories

**Examples:**
- "Add a parent portal to see student activities"
- "Export activity registration list to Excel"
- "Add help documentation for students"

## Tips for Writing Good Requests

### Be Specific
❌ Bad: "Fix the colors"
✅ Good: "Change the header background from blue to lime green (our school color)"

### Explain Why
❌ Bad: "Add a calendar"
✅ Good: "Add a calendar view because students are having trouble seeing which activities meet on which days"

### Describe What Success Looks Like
❌ Bad: "Make it better"
✅ Good: "Students should be able to filter activities by day and see only Monday activities when they select Monday"

### Use the Examples
Each template has example text in gray (called "placeholders"). These show you exactly what kind of information to provide. You can replace them with your own information.

### Don't Worry About Technical Details
You don't need to know how to code or use technical terms. Just describe what you need in plain language. For example:
- ✅ "Add a way to search for activities by name"
- ❌ Don't worry about saying things like "implement a search algorithm" or "add a database index"

## What Happens After I Submit?

1. **Automatic Assignment**: GitHub Copilot (our AI assistant) may be automatically assigned to work on your request
2. **Development**: The system will make the requested changes
3. **Review**: Changes will be reviewed before going live
4. **Notification**: You'll be notified when the work is complete
5. **Verification**: You can test the changes and provide feedback

## Need Help?

If you're not sure which template to use or have questions:
- Click **"💬 Ask a Question"** when creating a new issue
- Contact the technical team
- Check our [Development Guide](../docs/how-to-develop.md) for more information

## Example: Submitting a Bug Report

Let's walk through a real example:

**Situation**: The website is blue, but our school colors are white and lime green.

**Steps:**
1. Click "New issue"
2. Choose "Bug Report" template
3. Fill out the form:
   - **What's wrong?**: "The website colors are blue, but our school colors are white and lime green"
   - **What should happen instead?**: "The website should use white and lime green (hex #32CD32)"
   - **Which part affected?**: Select "Colors or styling (CSS)"
   - **How will we know it's fixed?**: 
     - "Header background is lime green"
     - "Text remains readable"
     - "Buttons match color scheme"
4. Click "Submit new issue"

Done! The system now has everything needed to fix the colors.

---

Remember: **There's no such thing as a "dumb" question or request!** The templates are here to help you get what you need. Just fill them out to the best of your ability, and the system will guide you through the rest.
